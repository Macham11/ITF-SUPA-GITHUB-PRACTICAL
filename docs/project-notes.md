# Project Notes

This document describes the ITF-SUPA GitHub practical assessment.

## Objectives
- Create a GitHub account with two-factor authentication
- Set up a repository with a README, .gitignore and license
- Organise the repository into folders
- Upload a document and a code file

## Folder Structure
- `docs/` holds project documentation
- `src/` holds source code
- `images/` holds screenshots and images
